## External runtime dependencies and assets — not redistributed

Python dependency manifests reference upstream packages; no Python environments, CUDA libraries or downloaded packages are bundled. Those dependencies retain their own licenses.

- **Wake detection:** [openWakeWord](https://github.com/dscripka/openWakeWord) framework and supporting assets are provisioned separately. The custom Hey Cube ONNX, its training checkpoints, synthetic/real recordings and datasets are excluded. See [wake-model provisioning](client/assets/models/README.md).
- **Piper:** implementation and voice models/configuration are separate downloads with separate terms. Review the [Piper project](https://github.com/OHF-Voice/piper1-gpl) and the chosen voice's model card; see [voice provisioning](client/assets/voices/README.md).
- **Kokoro / Whisper / LLMs:** model and voice weights are not bundled. Provision from the [Kokoro ONNX distribution](https://github.com/thewh1teagle/kokoro-onnx), the selected [faster-whisper model source](https://github.com/SYSTRAN/faster-whisper), or your chosen LLM provider. Review the exact downloaded versions/model cards.
- **Spotify Soloist:** obtain the receiver and your own key directly from [Spotify](https://developer.spotify.com/documentation/soloist). No Soloist archive, executable, key or session data is distributed here. Follow upstream download/use restrictions and keep notices with a local installation.
- **Spotify artwork:** fetched at runtime under Spotify's API terms; no album artwork, branding bundle, playlist mappings or OAuth tokens are included.

Unverified GIPHY art, PAC-MAN assets and all custom wake-training outputs are excluded. Their provenance is not a release gate for this source-only repository because they are not distributed. Adding any of them later requires a separate rights/provenance review.
