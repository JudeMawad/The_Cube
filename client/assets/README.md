# Pi assets

Voice operation requires a [user-provided wake model](models/README.md), openWakeWord supporting assets and a [Piper voice with matching configuration](voices/README.md). Model weights, training outputs and voice JSON are excluded from this public repository. See [setup](../../docs/SETUP.md) for configuration. Hardware-free tests need none of these assets.

`animations/source/` contains original eyes, ghost, heart and rocket GIFs generated by `tools/generate_cube_animation_samples.py`. Matching `.cubeanim` outputs are intentionally committed runtime assets so the Pi does not need Pillow for playback. They are covered by Cube's MIT license. No GIPHY or PAC-MAN artwork is distributed. See [display architecture](../../docs/DISPLAY_ARCHITECTURE.md) for conversion and runtime constraints.
